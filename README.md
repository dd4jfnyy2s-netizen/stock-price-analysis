# 株価分析アプリ

## 概要

Python・Flask・SQLiteを使用して作成した株価分析Webアプリです。

銘柄コードと期間を指定することで、株価データの表示や期間内の分析、株価推移のグラフ表示を行うことができます。

## 使用技術

* Python
* Flask
* SQLite
* HTML
* CSS
* JavaScript
* Chart.js

## 主な機能

* 銘柄コードによる株価検索
* 開始日・終了日の指定
* 指定期間の株価データ表示
* 期間内の平均株価の計算
* 前日比の計算
* 前日比率の計算
* 最新株価の表示
* 株価推移のグラフ表示
* 入力値のバリデーション
* SQLiteによる株価データの管理

## データベース

SQLiteを使用して株価データを管理しています。

### stock_pricesテーブル

| カラム    | 内容    |
| ------ | ----- |
| id     | データID |
| symbol | 銘柄コード |
| date   | 日付    |
| open   | 始値    |
| high   | 高値    |
| low    | 安値    |
| close  | 終値    |
| volume | 出来高   |

`symbol` と `date` の組み合わせにUNIQUE制約を設定し、同一銘柄・同一日の重複データを防止しています。

## 使い方

1. アプリを起動します。
2. 銘柄コードを入力します。
3. 開始日を入力します。
4. 終了日を入力します。
5. 「分析する」ボタンを押します。
6. 株価データ、分析結果、株価推移グラフを確認します。

## 入力バリデーション

以下のような入力エラーに対応しています。

* 銘柄コードが未入力の場合
* 日付が未入力の場合
* 開始日が終了日より後の場合
* 存在しない銘柄を指定した場合
* 指定期間に株価データが存在しない場合
* 前日比の計算に必要な2日以上のデータがない場合

## 工夫した点

### FlaskとSQLiteを組み合わせたWebアプリ

Pythonだけで処理するのではなく、Flaskを使用してWebブラウザから操作できるアプリとして構築しました。

また、株価データの保存にはSQLiteを使用し、SQLによる検索・絞り込みを行っています。

### 指定した期間によるデータ検索

銘柄コードと開始日・終了日を条件としてSQLを実行し、指定された期間の株価データだけを取得するようにしています。

### 入力エラーへの対応

正常な入力だけを想定するのではなく、未入力や日付の逆転、存在しない銘柄、データが存在しない期間などをチェックし、ユーザーに適切なメッセージを表示するようにしています。

### 株価データの視覚化

Chart.jsを使用して、取得した終値を折れ線グラフとして表示し、期間内の株価推移を視覚的に確認できるようにしました。

## ファイル構成

```text
flask_practice/
├── app.py
├── finance.py
├── finance.db
├── README.md
├── .gitignore
└── templates/
    └── index.html
```

### 各ファイルの役割

* `app.py`
  FlaskによるWebアプリの処理、入力値の取得、データ検索、画面表示を担当。

* `finance.py`
  株価データの分析処理を担当。

* `finance.db`
  SQLiteによる株価データを保存。

* `templates/index.html`
  Web画面のHTML、CSS、Chart.jsによるグラフ表示を担当。

## 起動方法

仮想環境を有効にした状態で、以下のコマンドを実行します。

```bash
python app.py
```

その後、ブラウザから表示されたアドレスにアクセスします。
